* eimg — 截图与 OCR 一体化工具包

状态： *0.1.0 开发中* （首轮：OCR；截图能力迁移在后续计划）

本仓库目前只有骨架（版本常量 + 构建入口 + openspec 工件），业务实现由后续任务补齐。
下文的能力清单、CLI 参数与键位均为 *计划中的契约* ，尚未落地。

* 安装

本轮尚未提供安装脚本；以下是计划中的入口， *首次安装需显式运行，配置不会自动安装*
（ =init= 与任何 hook 不下载、不安装任何东西）：

| 命令                                     | 用途                                             |
|------------------------------------------+--------------------------------------------------|
| =bin/eimg-ocr-setup --check=             | 只读体检：报告后端可用性、缺什么、装到哪         |
| =bin/eimg-ocr-setup --reuse-pdf-toc-ocr= | 复用 pdf-toc-ocr 已有的 venv（含 rapidocr 依赖） |
| =bin/eimg-ocr-setup --rapidocr=          | 新建 venv 并安装 rapidocr（onnxruntime 等）      |
| =bin/eimg-ocr-setup --tessdata=          | 补齐 tesseract 的 chi_sim + eng 语言数据         |

* 用法（CLI 契约占位）

| 参数              | 取值（计划）                      | 说明                               |
|-------------------+-----------------------------------+------------------------------------|
| =--backend=       | =auto= / =rapidocr= / =tesseract= | 后端选择； =auto= 按可用性探测     |
| =--lang=          | 如 =chi_sim+eng=                  | 识别语言（tesseract 语法）         |
| =--format=        | =text= / =org= / =json=           | 输出形态； =org= 供 Emacs 直接插入 |
| =--pdf-pages=     | 如 =1-5=                          | PDF 只识别指定页（渲染后 OCR）     |
| =--dpi=           | 整数，如 =300=                    | PDF 渲染精度，影响速度与准确率     |
| =--list-backends= | （无值）                          | 列出后端及可用状态后退出           |

退出码（计划）： =0= 成功 / =2= 参数错误 / =3= 后端不可用 / =4= 识别失败 / =5= 输入不可读。

* 已知边界

- *tesseract* 需自行补语言数据：系统默认只有 =afr= / =osd= ，中英文要跑 =bin/eimg-ocr-setup --tessdata= 。
- *rapidocr* 需 Python 环境（onnxruntime + numpy + pillow）：首轮复用已有 venv，或用 =--rapidocr= 新建。
